# nossa história — Marina & Elis

Esta versão do protótipo inclui os 23 capítulos que você contou, um mapa contínuo, diário pesquisável, formulário para criar/editar lembranças e missões-surpresa baseadas em perguntas e respostas.

## Testar
1. Extraia o ZIP.
2. Abra `index.html` em Chrome, Edge ou Safari.
3. Use **Nova lembrança** para registrar novos capítulos.

## Limitações importantes
- Os dados são guardados apenas no armazenamento local do navegador em que o app é aberto.
- Ainda não há sincronização entre dois celulares, login, nem diário compartilhado online.
- Fotos, áudios e vídeos ainda não são enviados; o campo de mídia serve para anotar o que você quer anexar depois.
- Para compartilhar com segurança entre Marina e Elis, a próxima etapa é hospedar o app e conectar um backend com autenticação e permissões, por exemplo Supabase.
- A data das fotos aleatórias foi informada como `12/2026`, que é futura em relação a alguns eventos da linha do tempo; deixei marcada para confirmar. Alguns eventos não tinham ano e estão sinalizados como “ano a confirmar”.

Faça backup das lembranças antes de limpar os dados do navegador.
